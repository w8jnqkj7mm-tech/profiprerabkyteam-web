# Negatívne logá s priehľadným pozadím

Dvanásť inverzných log, z ktorých bol odstránený ukážkový čierny panel. Ten je v dizajn
manuáli len ilustrácia, kde sa logo má používať — nie je súčasť loga. V pôvodnom exporte
(`*-on-black.svg`) bol zapečený ako `<rect>` na celú plochu, takže na akomkoľvek inom
tmavom podklade z neho vznikol viditeľný obdĺžnik.

Odstránený bol **iba** ten jeden obdĺžnik. Kresba je nedotknutá, nič sa neprekresľovalo
ani neprefarbovalo.

Rovnaké súbory sú uložené aj v dizajn systéme Profi Prerábky pod názvami `*-negativ.svg`.

| Súbor | Použitie |
| --- | --- |
| `profi-prerabky-team-negativ.svg` | hlavné logo webu (hlavička) |
| `profi-prerabky-negativ.svg` | Profi Prerábky bez „.team“ (pätička, stránka remesla) |
| `pan-elektrikar-{badge,lockup,mascot,head}-negativ.svg` | Pán Elektrikár, štyri úrovne |
| `pan-vodar-{badge,lockup,mascot,head}-negativ.svg` | Pán Vodár, štyri úrovne |
| `stolarstvo-pressburg-{badge,lockup}-negativ.svg` | Stolárstvo Pressburg |

Pri malých rozmeroch zostupuj k `head`. Na svetlý podklad patria `*-color.svg`, nie tieto.
